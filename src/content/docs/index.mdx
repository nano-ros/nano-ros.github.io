## What nano-ros is

**nano-ros** is a deterministic ROS 2 client library for microcontrollers, FPGAs, and RTOS based systems. It implements `ros2_control` hardware interfaces natively on the RTOS, so the actuator node is part of the ROS 2 graph instead of a dumb serial endpoint.

**ros2_HDL** is the code generation companion. It reads a VHDL entity port map and a URDF `<ros2_control>` block and generates the C `hardware_interface` binding, unit scaling, and CCSDS APID assignment.

## Why the architecture is space first

<CardGrid>
  <Card title="Space is the primary tier">
    SpaceWire and CCSDS are the default transport path for flight use. The architecture keeps this path first class.
  </Card>
  <Card title="Zero allocation after init">
    Static memory, bounded buffers, and compile time sizing keep the runtime predictable.
  </Card>
  <Card title="Hardware source of truth">
    VHDL and URDF define the generated binding. The register map is not duplicated by hand.
  </Card>
  <Card title="Independent recovery">
    A companion MCU can boot, scrub, monitor, and reset the FPGA or SoC without help from nano-ros software.
  </Card>
</CardGrid>

## The gap nano-ros fills

| Gap | Solution |
|---|---|
| Embedded ROS 2 nodes need native `ros2_control` | nano-ros exposes `hardware_interface` on the RTOS |
| Space systems need a flight transport path | nano-ros Space tier uses SpaceWire and CCSDS |
| FPGA register maps drift between HDL and C | ros2_HDL generates the binding from VHDL and URDF |
| Radiation hardened systems need a hardware guardian | Independent MCU companion handles boot, scrub, and reset |

## Two deployment contexts

nano-ros uses one firmware design for two deployment contexts.

- Space and safety critical, RTEMS on LEON and PolarFire SoC, SpaceWire and CCSDS transport
- Industrial embedded, Zephyr on supported MCUs and SoCs, zenoh transport

## Core rules

- Keep memory behavior predictable
- Keep transport replaceable
- Keep the interface layer separate from runtime
- Keep the site aligned with the implementation
- Keep Space as the first class target
