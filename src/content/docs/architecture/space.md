---
title: Space Targets
description: Space grade and radiation tolerant FPGA and SoC targets supported by nano-ros.
---

## RT PolarFire SoC

RT PolarFire SoC is a primary development target. It combines a RISC-V CPU cluster with programmable FPGA fabric on one die. For nano-ros, it is the main path for space first development.

## GR712RC

GR712RC is a primary space deploy target. It pairs well with RTEMS and SpaceWire.

## GR740

GR740 is the scalable multi core space target for compute heavier missions.

## GR765

GR765 is the newer hybrid target and belongs in the platform matrix once the upstream RTOS support is ready.

## RTG4 plus LEON3FT

A rad tolerant FPGA option for missions that want antifuse style configuration behavior.

## Xilinx Virtex 5QV

A space qualified SRAM FPGA target that requires configuration scrubbing.

## GRLIB

All LEON family targets use GRLIB for bus infrastructure and on chip peripherals.
