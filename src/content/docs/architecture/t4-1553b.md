## Overview

Tier 4 targets defense and aerospace platforms where SpaceWire is not available but MIL-STD-1553B is mandated. It is not required for space or industrial deployments and is not part of the default CMake configuration.

## MIL-STD-1553B basics

MIL-STD-1553B is a 1 Mb/s differential serial bus with a time-division multiplexing architecture (Bus Controller + Remote Terminals + Bus Monitor). It operates at 1 Mb/s and is adequate for joint state telemetry at up to 100 Hz with 7 joints.

GRLIB provides the `GR1553B` IP core as an AMBA APB peripheral. It implements both BC and RT modes. The core is available in the GRLIB GPL release.

## Wire format

T4 carries the same CCSDS framing as T0, packed into 1553B data words (16-bit, big-endian):

```
[1553B command word]         BC → RT: address, subaddress, word count
[CCSDS primary header]       packed into 1553B data words
[CCSDS secondary header]     CDS timestamp
[joint payload: N × 8 bytes] float64, big-endian
[CRC-CCITT: 2 bytes]
```

The same YAMCS Mission Database XML used for T0 decodes T4 telemetry without modification — both transports carry CCSDS packets.

## Callback contract

The GR1553B interrupt marks message receipt complete and posts to a semaphore. The `NR_TRANSPORT` RTOS task wakes on the semaphore and calls the subscribe callback. No callback is ever called from the ISR context. See [Transport Overview](/architecture/transport/overview/#callback-thread-safety-contract) for the full thread safety contract.

## Use cases

- Defense ground robots where the vehicle bus is 1553B
- Legacy aerospace programs with existing 1553B infrastructure
- Platforms where SpaceWire hardware is unavailable but CCSDS compatibility is required

## Bandwidth note

At 1 Mb/s with CCSDS overhead, T4 supports approximately 7 joints at ≤100 Hz. For higher joint counts or higher rates, T0 (SpaceWire, up to 400 Mb/s) is the correct choice.
